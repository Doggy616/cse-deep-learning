# 注安深度学习系统 V0.1

面向中国中级注册安全工程师四科考试的本地学习应用。使用 React、TypeScript、Vite、PWA 和 IndexedDB，无需账号，不依赖付费服务、云数据库或在线 AI。

**当前是可运行的原创演示版本，不是完整题库。** 内置“事故隐患排查治理”“机械设备检维修安全”两个专题、6 节课程和 4 道训练题。所有内容明确标注“原创演示、未经核验”，不计入正式成绩，不替代现行法规、权威教材或现场专业判断。尚未导入后续 16 份 Markdown 资料。

## 第一次预览（无需编程）

1. 在 Windows 安装 Node.js 24 LTS（或 22.12 及以上的 22.x），下载/克隆此仓库并解压。
2. 打开项目文件夹，在地址栏输入 `powershell` 后回车，依次执行：

   ```powershell
   npm ci
   npm run dev
   ```

3. 按终端显示的地址在浏览器打开，通常为 `http://localhost:5173`。终端保持打开；按 `Ctrl+C` 停止。
4. 如果 PowerShell 提示禁止执行 `npm.ps1`，将上述命令中的 `npm` 改成 `npm.cmd`，无需修改系统执行策略。

开发模式用于改代码；**离线缓存与安装请使用下面的生产预览**。`node_modules` 已在云环境安装时可直接启动，无需重复安装。云平台请使用平台提供的端口访问功能；仓库本身不提供公共托管网址。

## 生产预览与离线安装

```powershell
npm run build
npm run preview
```

终端通常显示 `http://localhost:4173`。首次联网打开后，生产版本会缓存页面、样式、脚本、图标与内置课程题目；无外部字体/CDN资源。缓存完成后断网刷新，仍可学习、做题并保存记录。

安卓手机安装：将 `dist/` 目录部署到提供 HTTPS 的静态站点**根路径**，手机用 Chrome 或 Edge 首次联网打开，等待资源缓存，再从菜单选择“安装应用”或“添加到主屏幕”。Windows Chrome / Edge 也可从地址栏或菜单安装。应用内在浏览器提供安装事件时显示“安装到设备”。浏览器具体菜单名称可能不同。

普通局域网 `http://电脑IP:4173` 可用于手机查看布局，但不满足手机 PWA 的安全上下文要求，不能据此验证离线和安装。应使用 HTTPS 站点。安装不是离线功能的前提；首次缓存成功后浏览器也能离线学习。

本版本配置 `start_url: /`，部署到 GitHub Pages 的 `/仓库名/` 子路径前，需要另行统一调整 Vite `base`、PWA 的 `scope/start_url` 与图标路径；不要直接将当前根路径构建当作子路径部署。无需任何服务器端业务接口。

## 建议先体验这一条学习路线

1. **首页及四科入口**：查看今日目标、已学专题和到期复习；从法律法规、管理、技术基础、专业实务进入专题。
2. **知识专题与深度课程**：打开“事故隐患排查治理”，阅读三节课程，点击“标记已学完”。两个专题都关联四科视角；四科入口不代表完整四科内容覆盖。
3. **综合题训练与逐项解析**：进入关联综合题，先故意选错提交，阅读每个选项的解析；多选题必须全选对才算掌握，不计部分分数。
4. **条件反转与变式训练**：比较“尚未修复”和“修复但尚未验证”的变化，重新判断。
5. **精准复习与学习记录**：错题立即进入待复习；答对后依次安排 1、3、7、14 天复习，之后维持 14 天；再错则立即重置。提前重练也会更新连续答对次数。统计仅代表演示练习表现，不是正式考试成绩。
6. **数据导出、导入及设置**：导出 JSON，清空记录后导入并二次确认，验证恢复。设置每日目标与大字阅读。

## 数据在哪里，如何保护

- IndexedDB 数据库 `zhuan-deep-learning` 的 `state` 对象仓库保存 `learning` 文档。记录包括课程完成时间、逐次作答、复习安排与设置；刷新可恢复。
- 不上传学习数据、不需要密钥；不同浏览器、设备、域名和端口各自独立，开发端口和预览端口也不共享数据。
- 浏览器清理站点数据、隐私模式、卸载或存储回收可能删除记录。重要数据请定期导出到安全位置。建议只用一个标签页学习，避免多个标签页同时覆盖记录。
- 导入仅支持本内容版本导出的 JSON 备份，最大 10 MB、50,000 次作答；先校验、显示摘要，再确认**替换**，不静默合并。
- 导入按内置题目重新核验答案、评分类别、来源版本和复习时间，拒绝不一致数据；仅白名单字段被重建。它用于数据完整性检查，并非防作弊系统，设备持有者始终可以修改本地记录。
- 导入不会接入资料、脚本或外部题库；备份版本不兼容时拒绝导入，未来需实现显式迁移。
- IndexedDB 读取失败时停止写入；保存失败时显示错误，不伪报保存成功。清空数据需二次确认；PWA 更新也由用户点击确认。

## 内容来源、审核与答案冲突

定义见 `src/model.ts`，内置数据见 `src/content.ts`：

| 结构 | 用途 |
| --- | --- |
| `Provenance` | 来源编号、名称、类型（原创演示/Markdown/官方）、版本、资料定位、审核状态、审核人和时间 |
| `AnswerClaim` | 不同来源、版本的答案声明 |
| `AnswerConflict` | 冲突来源、候选答案、说明、是否已人工解决 |
| `Question` | 科目、专题、情境、变式条件、选项及逐项解析、参考答案、正式题标志、来源和冲突 |
| `Attempt` | 所选答案、内容版本、来源、时间及 demo/formal/practice 评分类别 |
| `LearningData` | 备份结构版本、内容版本、课程进度、作答与复习记录、设置 |

`detectAnswerConflicts()` 比较归一化答案集合，发现分歧后生成待解决记录。未来接入资料时，需先完成题目标识/选项映射，再调用此检查并交人工核验；不会自动裁决哪份资料正确。

`eligibleForFormal()` 默认拒绝。只有非原创演示、显式启用正式题标志、已审核、审核人和时间齐全、答案选项合法且所有冲突已解决时，才允许正式评分。**当前正式题库为 0 题**，所有内置题均为未核验原创演示。V0.1 没有后台审核工作台或 Markdown 批量导入功能；不得仅修改标志绕过人工审核。

## 验证与测试

```powershell
npm test
npm run build
```

基础测试涵盖评分隔离、冲突检查、多选判定、间隔复习、IndexedDB、备份校验和用户交互流程，包括存储失败提示与导入/清空确认。

真实浏览器测试（首次需要下载免费 Chromium 测试浏览器）：

```powershell
npx playwright install chromium
npm run build
npm run test:e2e
```

测试会自动启动 4173 端口，分别以桌面和 390px 手机尺寸验证完整学习闭环、导出/清空/恢复、刷新持久化、Service Worker 控制、断网重载及离线答题。Linux 如缺少系统库可使用 `npx playwright install --with-deps chromium`（需系统安装权限）。已安装系统 Chromium 的云环境可执行：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

浏览器模拟不等于安卓或 Windows 真机认证。真机验收请在 HTTPS 部署上完成安装、断网重开、练习、重启浏览器与备份恢复。

## 开发目录

```text
src/App.tsx          六个页面及学习交互
src/content.ts      原创演示课程和题目
src/model.ts        内容模型、审核门槛、答题与复习规则
src/storage.ts      IndexedDB、导出和严格导入校验
src/styles.css      桌面/手机自适应样式
src/*.test.*        基础与组件测试
e2e/                生产版本真实浏览器测试
public/             自带本地图标
vite.config.ts      构建、PWA 缓存和测试配置
```

依赖由 `package-lock.json` 固定，使用 `npm ci` 重现。无需 Python、数据库服务、GPU 或在线 AI。`.github/workflows/ci.yml` 在提交/PR 时执行基础测试和生产构建。后续建议在获得资料后逐份登记来源、清理格式、人工核验及处理冲突，再扩充课程和正式题库。
